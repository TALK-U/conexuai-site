Verify before you install

The download link expires after 30 minutes; come back and redeem again if it does. Once you have the file, always compare its SHA-256 with the value shown on this page:

  1. Shift + right-click in your downloads folder and choose "Open PowerShell window here";
  2. Run Get-FileHash .\Conexuai-Setup-0.5.2.exe -Algorithm SHA256 (use the file name you actually got);
  3. Compare the Hash character by character with the value on this page. If they differ, do not install — contact us instead.

In Command Prompt, certutil -hashfile FILENAME SHA256 gives the same result.
