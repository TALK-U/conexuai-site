Security & Privacy Statement

Alpha · 2026-09-29 · Reference translation — the Chinese version prevails.

[Draft — pending final version] This page is a draft. Every sentence is backed by a specific implementation and will be checked line by line before launch. This version is not a final commitment.

1. Where your data lives

  1. This software is a local-first desktop application. All of your runtime data (message bus, group configuration, logs) is stored only on your own computer, in %APPDATA%\MAH.
  2. When you uninstall, the uninstaller explicitly asks whether to keep or delete your local data; the default is to keep it. The choice is yours.

2. Network behaviour

  1. The software's built-in services bind only to the loopback address 127.0.0.1 and open no ports to your LAN or the internet.
  2. Alpha has zero telemetry: the software contains no usage statistics or reporting code, sends no usage data to our servers, and works fully offline.

3. Your accounts & credentials

  1. The software does not host your accounts at AI providers, and never handles or stores your API keys or passwords. Task dispatch passes only through bus files on your own machine.

4. Local account password

  1. Your local login password is stored only as an irreversible derived verifier (a scrypt hash) on your own computer. The password itself is never written to disk, logs, or the bus, and verification happens only inside the local main process.
  2. This password locks the interface, not the data on disk. This product stores all data locally in plain form; a technically skilled person on the same machine could bypass the interface and read the files directly. This version does not provide data-at-rest encryption and does not imply that it does.
  3. The password cannot be recovered. There is no cloud, no email reset, no security questions — this is the direct cost of "all data stays local, never handled by us". The only remedy for a forgotten password is deleting account.json and recreating the account; your data is not affected (account and data are two separate things).
  4. What "Keep me signed in" means: it skips the login page on next launch — it is not "remember my password". Turning it off immediately restores password verification on every launch.

5. Logs & crash information

  1. The software's logs record only file names and error information, never the content of your messages.

6. Installation & updates

  1. Launch-at-startup is off by default; a startup entry is written only when you explicitly enable it in Settings, and it is removed on uninstall.
  2. Every installer published on our website ships with a SHA-256 checksum and verification instructions, so you can confirm the package has not been tampered with.

7. Website application form

  1. The Apply page collects only your questionnaire answers and your email address. The form uses no third-party form services or analytics SDKs, and the page contains no tracking scripts.
  2. The application page uses Cloudflare Turnstile for human verification (a hosted anti-abuse component to block bot submissions); apart from this, the page loads no other third-party scripts.
  3. Application data is stored via Cloudflare Pages Functions in KV and deleted automatically after 180 days. It is used solely for beta qualification review and notification, and for no other purpose. During Alpha nothing is forwarded through any email service: we read the application list directly, and invitation emails are sent by hand.

8. Vulnerability response

  1. If you discover a security vulnerability, please report it through the beta channel or the contact published on our website. We commit to acknowledging receipt within 48 hours.
